# Expenses — reimburse + supplier payments (owner, 3 Nov 2026)

- Two kinds in one table `expense_claims.kind`: `reimburse` (staff paid first, attach receipt/own transfer slip) · `supplier` (company transfers to the supplier, attach bill/invoice — mandatory, no "no receipt" option, always `payout='transfer'`, payee bank fields required; DB constraint `expense_claims_supplier_fields`). **One approval, by finance** (owner 3 Nov: managers don't approve; the owner's "approve" is in the SCB app after the file is uploaded). New claims start at `pending_finance` (migration 20261103160000); `pending_manager`/`expense_manager_decide` are legacy only.
- Transfer stages (owner 3 Nov): finance approves → **รอส่งไฟล์ธนาคาร** (approved+transfer, `exported_at` null: pick company tile → filter person → tick → export SCB file; 1 file = 1 company) → **รอโอน (ส่งไฟล์แล้ว)** (`exported_at` set; owner approves in the SCB app) → finance ticks, attaches ONE slip, "โอนแล้ว" (slip copied into each owner's folder `<userId>/slips/`). "ย้ายกลับไปรอส่งไฟล์" clears `exported_at`. `ExpenseStatusPill` shows these stages (needs `payout` + `exportedAt`). Row text: "จ่ายจาก <company>" · how it's paid · "บัญชีปลายทาง" (owner found "โอนให้ supplier / โอนเข้า" confusing).
- **SCB file = CPX Toolkit 1.1.2 upload .txt** (owner's template `file_template/CPX_Toolkit_Template-SCB.08.69.xls`; format reverse-engineered from its VBA, see header of `lib/services/bankTransferFile.ts`): UTF-8 no BOM, `|`-separated, CRLF, HEADER/BCHDET/TXNDET×n/TRAILR, TXNDET = 28 fields, branch `0111`, fee `BEN`, product `OAT` (template default; `3PT` selectable). SCB destinations only + SCB check digit (`isScbAccount`); other banks are reported as skipped — the other-bank template `CPX_Toolkit_Template-08.69.xls` (ORFT/SMART) is not built yet. Names/remarks stripped of the toolkit's forbidden chars (`scbText`). One file per company; debit account stored in `companies.scb_debit_account`, set by finance through `set_company_scb_debit_account()` (migration 20261103140000). Golden-file test in scripts/test-expense-rules.mjs. `file_template/` holds real account numbers/emails — never commit it.
- Month-end report (button "สรุปสิ้นเดือน") reproduces accounting's Excel form "EXPENSES REIMBURSEMENT" (original: ~/Downloads/Reimbursement.xlsx, one sheet per claim): summary sheet + one sheet per person + supplier sheet. Month = `expense_date`; statuses approved+paid. Category → form section via `formSectionOf()` (travel=Taxi, parking=Expressway/Parking, fuel=Gasoline, meal=Entertainment, phone=Telephone, rest = Others, or Others VAT 7% when `vat_amount>0`). The original template's Total Transport only summed Gasoline and reused the Entertainment label for Telephone — ours sums all three and labels correctly.
- `vat_amount` is VAT included in `amount` (UI toggle computes 7/107). Company filter: `company_id` null = owner's home company (resolved in `toNamedClaim`).
- **Category = accounting form section** (owner 3 Nov): staff pick one of the 7 Excel sections (`SECTION_LABEL`; stored as `category` + `vat_amount`, mapping `SECTION_CATEGORY`; `other_vat` ⇔ vat>0, VAT auto 7/107). Not sure → typing the description auto-picks via `suggestSection()`: own approved/paid claims with similar text (bigram ≥0.6) win, else keyword rules `guessSection()` built from the 1,218 historical rows of Reimbursement.xlsx (90% accurate; rule order matters — fuel before "ขนของ", shipping/Lalamove = Others). Remaining misses are rows that only name a place/person, or where accounting itself was inconsistent (cakes, Lalamove).
- Finance edits section/details before approving or paying via `ClaimEditModal` → `updateClaimDetails()` (amount only while pending_finance; changing payee/amount clears `exported_at`).
- UI (owner 3 Nov): everything expense-related lives under ONE sidebar menu "เบิกค่าใช้จ่าย" (ใบเบิกของฉัน · อนุมัติ / โอนจ่าย) — not under "รออนุมัติ" (owner couldn't find it there). Form picks the company first (shows the debit account), uses `ChoiceTiles` with icons from `components/expenses/expenseVisuals.ts`; the manage page's stage tabs are `StatusTabs` with counts from `countPending()`; companies in รอส่งไฟล์ are `StatusTabs` too.
- **No more "รวมกับเงินเดือน"** (owner 3 Nov): reimbursements are always transferred (`createClaim` forces `payout='transfer'`; finance approval no longer chooses). Payroll-linked code (payrollService, `payroll_month`) stays for legacy rows only. Row shows the money flow: "โอนจาก <company> (SCB •••xxxx) → เข้าบัญชีพนักงาน/ร้าน <bank acc · name>".
- Finance can tick many claims in every stage: bulk approve (รออนุมัติ), export (รอส่งไฟล์), mark paid (รอโอน). Receipt/slip thumbnails open the shared `Lightbox` (components/aoo, ported from aoosocial; `UatCaseModal` still has its own inline copy — switch it when that file is free).
- Manage list = column rows (รายการ · บริษัท · วันที่ · ยอด ฿ · สถานะ); no VAT/category text in the row (icon shows the category). Row click → `ClaimDetailModal`: left = `ReceiptGallery` (big image, thumbnails, Lightbox), right = details + timeline; approve/reject/edit/mark-paid live there.
- Category tiles: one horizontal-scroll row (`ChoiceTiles scroll`), ordered by `SECTION_BY_POPULARITY` (historical counts). Manage rows show the first receipt image (`ClaimThumb` + `useFirstReceiptUrls`, one signed-URL request per list; count badge when >1 file). Up to 10 files per claim; finance can remove/add files in `ClaimEditModal` (`updateClaimDetails` keepPaths/newFiles — removed files stay in storage).
- Manage list filters = shared `FilterBar` + `FilterSelect` (search · person · company · category), apply to every stage; in รอส่งไฟล์ the company comes from the logo tiles instead. Row: description bold first line, requester name below (click = person filter), category column = icon + short label.
- Person filter is cleared automatically when that person has no claim in the open stage (bug 3 Nov: the select showed "ทุกคน" while still filtering, list looked empty).
- Every SCB export also stores the exact .txt in bucket `expense-receipts` at `exports/<companyId|none>/<stamp>_<lines>_<totalCents>.txt` (`saveExportFile`); "ไฟล์ที่ส่งออกแล้ว" (รอส่งไฟล์/รอโอน tabs) lists and re-downloads them as `SCB_file_reference_<stamp>.txt` (owner 4 Nov). Files exported before this have no copy.
