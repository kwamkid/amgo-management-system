## Why this layout (owner, 4 Nov 2569)
1. **A library of what was built, fixed and learned**, so the same mistake is not made twice.
2. **Fewer tokens**: English only · this index, then headings, then only the range needed · one small file per topic in progress.
3. **Fewer bugs**: grep `bugs/bugs_fixed.md` and `knowledge/learning/` before changing code · a lesson seen twice becomes a rule in `.claude/rules/`.

## Where things go
| Kind | File | Note |
|---|---|---|
| Work not started / parked | `jobs/todo.md` | one `## <emoji> <Topic> — <date>` section per topic |
| Work in progress: open items + resume note | `jobs/doing/<topic>.md` | one file per topic (parallel chats never share a file) |
| Finished topics | `jobs/done/<YYYY-MM>.md` | section moved here, newest on top, when its last item closes |
| Check due on a date | `jobs/followups.md` | `- [ ] YYYY-MM-DD · topic · check → action` · never blocks closing |
| Check only the owner can do (real shop, money, device) | `jobs/owner-checks.md` | never blocks closing |
| Test cases for the tester | `UAT board (amgo dev tracker)` | case ids go on the topic’s done line · `uat.md` |
| Roadmap / priorities | `jobs/devplan.md` |  |
| Plan for one feature | `jobs/plans/<plan>.md` | finished → `jobs/plans/done/` |
| Loose idea | `jobs/ideas.md` |  |
| Bug found, not fixed | `bugs/bugs.md` | `## YYYY-MM-DD · area · symptom` |
| Bug fixed: symptom → root cause → fix | `bugs/bugs_fixed.md` | new entry on top · grep, never read whole |
| Lesson / technique / trap | `knowledge/learning/<topic>.md` | seen twice → rule in `.claude/rules/` |
| Hard rule, shared component / service registry | `.claude/rules/<topic>.md` | outside project/ · auto-loads by `paths:` |
| What the app can do (customer wording) | `features/app-features.md` | feeds web · content · marketing |
| Outside systems and their status | `features/platforms.md` | by type, live / partial / planned / paused / none |
| Cost · ISO · billing · business plans | `business/` |  |
| Audits · handoffs · runbooks · references | `knowledge/` |  |
| Old, superseded notes | `archive/` | history only |
| Private data (customer data, keys, backups, screenshots) | ``memo/` (not in git)` | never copy into project/ |

Closing a topic: 0 open items in its doing file → move the section to `jobs/done/<YYYY-MM>.md`, delete the doing file. Follow-ups, owner checks and UAT cases never keep a topic open. Every report ends with one line: ✅ ปิดจ๊อบได้ · ⏳ ปิดได้หลัง <x> · ❌ ยังเหลือ N ข้อ.
