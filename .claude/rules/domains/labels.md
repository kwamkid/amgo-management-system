# Thai OCPB (สคบ.) labels — 30 Oct 2026

Owner: build the round's stickers, share one link, the factory abroad (Hape Ningbo) prints them. Samples = `01-AGD/สคบ/*.png` (50×50 mm).

- **Data in amgo DB** (owner: "จำไว้ใน db"): `label_specs` layered `'*'` (all) → round brand → part brand (`import_round_items.source`, lower-case) → group (`grp`) → product (code). null = inherit. Kept per brand+code, not per round → filled once, reused next round. `label_rounds` = per-round import month (default = month of `arrive`), spare % (default 2, copies = ceil(qty × (1+%))), default size, `share_token`. Access (owner 30 Oct): `import_access` OR role admin/manager (active) — managers view + edit + add; brand managers without that role get 403. `labelGuard` checks, then uses the service role (import tables stay import_access-only by RLS); label tables RLS = `label_can_view()` / `label_can_edit()`.
- Price = product `price` override → SRP Calculator `srp_products.our_price_thb` (sku = code; owner chose SRP) → item `our_price` (agreed) → aoo shelf price (`aooPrices()`, MCP). SRP Calculator had only 33 priced Hape models on 30 Oct → C1: 23 SRP · 61 aoo · 87 none (new models) — owner fills those; never use brand USD SRP × fx on a label. Required on every label: warning · age · manufacturer · country · importer · address · price (`REQUIRED` in resolve.ts); `tis_type` (1–6 = types on licence น34375-5969/685) is optional, not flagged.
- QR = AGD's TISI licence page `https://appdb.tisi.go.th/Q/i.php?d=2095240074` (same on every sample; owner wants it fixed) — regenerated as vector, URL lives in the `'*'` row. TIS mark = traced from the sample (`tisMark.ts`), ring drawn as a true circle.
- **Rendering (`lib/labels/render.ts`)**: pdf-lib can't shape Thai (marks collide) → HarfBuzz (`harfbuzzjs` wasm) shapes Noto Sans Thai + Noto Sans Latin subset (`lib/labels/fonts`), glyph outlines become paths → factory needs no Thai font. Auto-fit: body starts 7 pt, shrinks to fit; < 4.5 pt or QR module < 0.25 mm = warning on the page. Thai line breaks via `Intl.Segmenter('th')`.
- **PDF (`lib/labels/pdf.ts`)**: one file per size; modes `sheet` (A4 + crop marks, 3×5 at 50×50) · `single` (page = label, all copies) · `master` (one page per code). Each glyph and each label is a shared Form XObject — first try with drawSvgPath was 25 MB / 1.6 GB RAM / 18 s; now 15,152 labels = 3 MB, ~5 s (dev 8 s). Served directly (not the queue: no storage room, factory waits for a download). `maxDuration = 60`.
- `next.config.ts`: `harfbuzzjs` in `serverExternalPackages` + fonts/wasm in `outputFileTracingIncludes['/api/labels/*']` — without them prod fails silently like the docx fonts did.
- API: `/api/labels?r=` (GET round incl. fit per line · PUT settings / `share:true|false`) · `/api/labels/specs` PUT (all-null row = delete) · `/api/labels/preview` + `/api/labels/pdf` take `?r=` (login) or `?t=` (share token) · `/api/labels/share?t=` public JSON, no cost. Factory page `/labels/<token>` is English/Chinese; PDFs are built live, so edits after sharing reach the same link.
- Testing on real data: create a temp `label_rounds.share_token`, then delete the row — never leave test tokens (they are public links).

- **PDF scale trap (fixed 30 Oct):** glyph scale k ≈ 0.0018 must be written with significant digits (`sc()` in pdf.ts), never `f3()` — 3-decimal rounding made glyphs 10–25% off while advances stayed right (letters spread/squashed in PDF only; the SVG preview looked fine). Line breaks: `keepTogether()` in render.ts merges ICU splits like อุด|ตัน and keeps "18 เดือน" / "290 บาท" together. A4 footer uses the WinAnsi standard font → ASCII only.
- **Printing (owner 30 Oct):** same method as AOO bills — `lib/utils/printPdf.ts` (port of aoocommerce `lib/print-pdf.ts`): desktop = blob in a hidden iframe → print dialog; mobile = tab pre-opened before any await (iOS data URL). `LabelDownloads` "พิมพ์" uses it on both the admin and factory pages. Don't click it from browser automation — the native print dialog blocks the extension.
- **Self-print limits (owner 30 Oct):** "single" for a whole round = 15,130 pages → Chrome print preview hangs on "Loading preview". `LabelDownloads` counts pages (`perSheet()` in types.ts) and disables Print over 300 pages (download instead); admin can pick codes + copies each (`/api/labels/pdf … &codes=…&each=N`). Downloads fetch the blob first so the button spins (a plain link looked frozen ~10 s). Line pitch 1.32× body / 1.28× warning keeps C1 at ≥ 4.5 pt body.
