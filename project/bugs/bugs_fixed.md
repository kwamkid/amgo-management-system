## 2026-11-10 — Working a swapped day off: can't check out · fixed `08232b6`
- **Symptom:** staff who filed a schedule swap in advance (worked_date = today) check in on their day off, then can't check out.
- **Root cause:** the check-in path in [useCheckIn.ts](/hooks/useCheckIn.ts) opened the undismissable `SwapDayPrompt` on `expectedMode === 'off'` alone, without `hasSwapFor` (the page-load path checks `swapFiled`). `createSwap` then rejects the duplicate ("มีใบสลับวันหยุดที่ใช้วันนี้อยู่แล้ว"), the modal never closes and covers the checkout button. Refresh escaped it. `expected_work_mode` ignores `schedule_swaps`, so the mode is still 'off'.
- **Fix:** check-in checks `hasSwapFor` too · [SwapDayPrompt.tsx](/components/checkin/SwapDayPrompt.tsx) closes on the duplicate error as a fallback.
- **Lesson:** an undismissable modal needs the same "already answered?" gate on every path that opens it, plus an exit when submit says it's already done.

## เอกสารบริษัท — เพิ่มเติม

### 2026-08-22 — เอกสารบนมือถือตกบรรทัดคำละบรรทัด
- **ต้นเหตุ:** แผ่นเป็น A4 กว้าง 794px ตายตัว (ต้องตายตัว บรรทัดจะได้ตรงกับตอนพิมพ์) แต่มี `max-w-full` ติดอยู่ → จอ 390px **บีบแผ่นแล้วข้อความไหลใหม่** คอลัมน์หัวจดหมายเหลือ ~100px
- **แก้:** ถอด `max-w-full` แล้วห่อด้วย [FitToWidth](/components/documents/FitToWidth.tsx) ที่ **ย่อทั้งแผ่นด้วย transform** — บรรทัดยังขึ้นเหมือนเดิมทุกประการ
- **⚠️ กับดักซ้อน:** `transform` ต้องอยู่ใน `@media screen` เท่านั้น · ตอนพิมพ์แผ่นเป็น `position:absolute` ถ้า ancestor มี transform **แม้แต่ `scale(1)`** ancestor จะกลายเป็นจุดอ้างอิงแทนหน้ากระดาษ แล้วแผ่นหลุดออกนอกหน้า

### 2026-08-22 — พิมพ์แล้วได้หน้า 2 ว่างเปล่า
- **ต้นเหตุ:** แผ่นตั้ง `min-height: 297mm` = เท่ากระดาษ A4 พอดีเป๊ะ ซึ่งล้นได้ 2 ทาง
  1. 297mm = 1122.5px เบราว์เซอร์ปัดเป็น 1123px → ล้นครึ่งพิกเซล
  2. ผู้ใช้ตั้ง **Margins = Minimum** → กรอบหน้าเล็กกว่า A4 แผ่นเต็มความสูงจึงไม่มีทางลง
- **แก้:** `min-height: calc(100vh - 1px)` — ในโหมดพิมพ์ `vh` คือความสูงกรอบหน้าจริงหลังหักขอบที่กล่องพิมพ์กำหนด ลบ 1px กันปัดเศษ
- **⚠️ เครื่องทดสอบจับไม่ได้:** `Page.printToPDF` ให้ "1 หน้า" ทั้งค่าเก่าและค่าใหม่ ทั้ง 3 แบบขอบกระดาษ · แก้ถูกเพราะเดาจากกลไก ไม่ใช่เพราะวัดเจอ (เจ้าของยืนยันทีหลังว่าหายจริง)

- **Symptom:** in the label PDF, bold lines looked letter-spaced and regular lines squashed; the on-page SVG preview was correct.
